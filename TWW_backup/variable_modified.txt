一、四绿字基础配置 (STAT_CONFIG in config.js)
================================================================================
位置：config.js - STAT_CONFIG 对象
用途：定义四个属性的基础元数据

【爆击 Critical Strike】
STAT_CONFIG.c.def_conv = 45.99          // 转化率：45.99 Rating = 1%
STAT_CONFIG.c.def_base = 5.0          // 基础百分比：5.0%
STAT_CONFIG.c.base_limit = 1380      // DR 第一阈值：30% × 45.99 = 1380
STAT_CONFIG.c.step_limit = 460       // DR 步长：10% × 45.99 = 460

【急速 Haste】
STAT_CONFIG.h.def_conv = 44.01          // 转化率：44.01 Rating = 1%
STAT_CONFIG.h.def_base = 0.0          // 基础百分比：0.0%
STAT_CONFIG.h.base_limit = 1320      // DR 第一阈值：30% × 44.01 = 1320
STAT_CONFIG.h.step_limit = 440       // DR 步长：10% × 44.01 = 440

【精通 Mastery】
STAT_CONFIG.m.def_conv = 45.99          // 转化率：45.99 Rating = 1%
STAT_CONFIG.m.def_base = 0.0          // 基础百分比：0.0%
STAT_CONFIG.m.base_limit = 1380      // DR 第一阈值：30% × 45.99 = 1380
STAT_CONFIG.m.step_limit = 460       // DR 步长：10% ×45.99 = 460

【全能 Versatility】
STAT_CONFIG.v.def_conv = 53.97          // 转化率：53.97 Rating = 1%
STAT_CONFIG.v.def_base = 0.0          // 基础百分比：0.0%
STAT_CONFIG.v.base_limit = 1619      // DR 第一阈值：30% × 53.97 = 1619
STAT_CONFIG.v.step_limit = 540       // DR 步长：10% × 53.97 = 540

二、收益递减 DR 效率表 (utils.js - getDRTiers)
================================================================================
位置：utils.js - getDRTiers() 函数
用途：定义 DR 各阶段的效率百分比

DR_TIERS = [
  { limit: 30,  eff: 1.0 },   // 0-30%:   100% 效率
  { limit: 40,  eff: 0.9 },   // 30-40%:   90% 效率
  { limit: 50,  eff: 0.8 },   // 40-50%:   80% 效率
  { limit: 60,  eff: 0.7 },   // 50-60%:   70% 效率
  { limit: 80,  eff: 0.6 },   // 60-80%:   60% 效率
  { limit: Inf, eff: 0.5 }    // 80-200%:  50% 效率
]

注意：精通的阈值会按 scale = critConv/masteryConv 缩放

================================================================================
六、默认多项式系数 (config.js - POLY_DEFAULT)
================================================================================
位置：config.js - POLY_DEFAULT 常量
用途：无 SimC 数据时的兜底模型

POLY_DEFAULT.a2 = 0                 // 二次项系数
POLY_DEFAULT.a1 = 0.0001           // 一次项系数
POLY_DEFAULT.a0 = 1.0               // 常数项

模型公式：y = 0.0001x + 1.0

================================================================================
七、SimC 拟合配置 (solver.js - processSimData)
================================================================================
位置：solver.js - processSimData() 函数
用途：定义 SimC 数据拟合的参数

FIT_MODE_AUTO = 'auto'              // 智能选择：R²≥0.99 用线性，否则二阶
FIT_MODE_LINEAR = 'linear'          // 强制线性拟合
FIT_R2_THRESHOLD = 0.99             // 线性拟合 R²阈值
FIT_MIN_POINTS = 4                  // 每段最少数据点要求

分段点计算：
  cap1 = base_limit
  cap2 = base_limit + step_limit
  cap3 = base_limit + 2 × step_limit

十、延拓修正配置 (utils.js)
================================================================================
位置：utils.js - getGainWithExtension() 函数
用途：断点跳变修正

EXTENSION_FORMULA = (nextM/curM) × (pM1/pM2)
  - pM1: 断点前区间在 limit 处的 multiplier
  - pM2: 断点后区间在 limit 处的 multiplier

================================================================================
十一、smoothScores 累积修正 (solver.js - generateTrajectory)
================================================================================
位置：solver.js - generateTrajectory() 函数
用途：Delta 图可视化平滑

SMOOTH_FORMULA = score × Π(pM1/pM2)  // 累积所有已跨越断点的修正因子
应用条件：val > bp.limit  // 只要当前值超过断点就应用

十二、文件修改清单 (更新 TWW 时需要修改的文件)
